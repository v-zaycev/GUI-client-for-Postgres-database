# GUI-client-for-Postgres-database

Клиент-серверное приложение для управления стационаром больницы. Реализовано на Python (PyQt6) с бэкендом на PostgreSQL. Система поддерживает разграничение прав доступа (RBAC), триггерную логику целостности данных, автоматическое перераспределение пациентов и экспорт аналитических отчётов.


## Функциональность

### Для всех пользователей
- Просмотр журнала пациентов
- Просмотр справочников (палаты, диагнозы)
- Просмотр аналитических отчётов

### В зависимости от роли

Роль: basic_role \
Права: Добавление/изменение/удаление только пациентов

Роль: advanced_role \
Права: Полное CRUD для пациентов, палат и диагнозов

Роль: super_role \
Права: Всё из advanced_role + управление пользователями

### Отчёты (с экспортом в XLSX / CSV / PDF)
- Статистика по палатам - заполненность, свободные места, процент занятости
- Статистика по диагнозам - распределение пациентов, загруженность по каждому диагнозу

### Представления (VIEW)
- people_view - пациенты с диагнозом и палатой
- wards_view - палаты с диагнозом
- ward_occupancy_report - отчёт по заполненности палат
- diagnosis_statistics - отчёт по статистике диагнозов
- permissions_table - права доступа к таблицам для текущей роли
- roles_table - доступные роли для текущего пользователя

### Триггеры (INSTEAD OF)
- Вставка/обновление/удаление через представления с проверками:
  - Совместимость диагноза палаты и пациента
  - Контроль свободных мест (max_count)
  - Уникальность названий
  - Ограничения длины (1-20 символов, max_count 1-20)


## Ролевая модель

Пользователи аутентифицируются через таблицу users, после чего выполняют:

CALL set_role('username');

Что делает процедура:
1. Определяет роль пользователя (basic_role / advanced_role / super_role)
2. Выполняет SET ROLE для соответствующей роли
3. Далее все запросы идут с правами этой роли

### Права по ролям

| Объект | basic_role | advanced_role | super_role |
|--------|------------|---------------|------------|
| people_view (SELECT) | ✅ | ✅ | ✅ |
| people_view (INSERT/UPDATE/DELETE) | ✅ | ✅ | ✅ |

| wards_view (INSERT/UPDATE/DELETE) | ❌ | ✅ | ✅ |

| diagnosis (INSERT/UPDATE/DELETE) | ❌ | ✅ | ✅ |
| users | ❌ | ❌ | ✅ |
